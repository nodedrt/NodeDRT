NODE_ONE — what was modelled, and how
=====================================

This file records what the look presets were fitted against, so the claim in
NOTICE-NodeOne.txt can be checked rather than taken on trust.


The seven film looks
--------------------
Each look is a set of values native to Node One DRT. None of them is a LUT, a
profile, or a copy of anything: each is the result of driving this transform's
own parameters until its OUTPUT matched a reference rendering.

Reference renderings were produced with spektrafilm (Andrea Volpato,
CC BY-SA 4.0), run with auto-exposure off, spatial and stochastic effects off,
and the canonical neutral print settings, so each reference is a fixed colour
transform rather than something that depends on the picture.

    1  Vision3 250D / 2383          kodak_vision3_250d / kodak_2383
    2  Vision3 250D / 2393          kodak_vision3_250d / kodak_2393
    3  Vision3 500T / 2383          kodak_vision3_500t / kodak_2383
    4  Portra 400 / Endura          kodak_portra_400   / kodak_portra_endura
    5  Ektar 100 / Ultra Endura     kodak_ektar_100    / kodak_ultra_endura
    6  Pro 400H / Crystal Archive   fujifilm_pro_400h  / fujifilm_crystal_archive_typeii
    7  Gold 200 / Supra Endura      kodak_gold_200     / kodak_supra_endura

Fitted over 3727 colours spanning a regular grid of the cube, a dense neutral
ramp and a cluster around skin, weighted towards the places the eye judges
first. Error is measured in Oklab.

A fitted look is a deliberate approximation of its reference, not a
reproduction of it.


The "Classic" look
------------------
Obtained the same way, against a reference display rendering rather than a film
one, for people who want that familiar conversion. Fitting against what a
renderer produces is not derivation from that renderer: the output of a program
is not covered by the program's own licence.


The engine's own defaults
-------------------------
Node One DRT's defaults were set by measurement against the same film
references — where skin chroma lands (0.0897, which is film's own value), what
the midtone slope is (0.1448 on film, 0.1473 here), and how chroma falls away
as a source is exposed up. These are measurements of physical materials, which
are facts.


Verification
------------
Every look is checked before it ships, by drt2/check_looks.py: finite output,
inside 0..1, a monotone grey ramp over sixteen stops, and monotone luminance
along twelve colour ramps over five decades. That check has rejected looks
three times; each rejection was a real defect that would have banded on a
gradient.

The shipping kernel is checked against the design reference by drt2/parity.py
over 2000+ colours spanning seven decades, and must agree to float32 precision.


Texture: grain and halation (version 1.1, 28 October 2026)
----------------------------------------------------------
A new group, Texture, with two sub-sections, Grain and Halation, computed by
the plugin itself (src/core/NodeTexture*) on the log image before the display
transform. Both are off by default.

Grain (65mm, 35mm). Per-channel grain strength as a function of the channel's
DaVinci Intermediate value, measured on grey patches; channel correlation
R-G 0.30, R-B 0.25, G-B 0.45; separable spatial kernels per gauge measured at
UHD and scaled with the frame height (the field is point-sampled below UHD,
as measured at HD). Hash noise with a valid convolution, so no tile seams and
identical GPU and CPU results.

Halation. Source = a piecewise-linear curve of the DI-encoded luminance;
spread = a radial kernel stored as six separable terms (4K UHD, scaled with
the frame width, evaluated at half resolution on large frames); added in the
domain T(l) = (l + 0.0482)^0.3635 with layer weights R 1.074, G 0.282,
B 0.100. Only the excess of the surroundings over the pixel's own source is
added. Softness (0 to 1) then diffuses the halo with a gaussian of unit sum
(sigma up to 1.5 x the kernel radius): same total light, smoother profile.

These constants were fitted by measuring film-emulation renders. Only the
numbers are used.


False Color: Stop Zones (version 1.2, 28 October 2026)
------------------------------------------------------
New False Color Mode menu. Stop Zones (default) reads the true scene
luminance - input decoded by its log curve, Y row of the input gamut - in
stops from 18% grey, in fifteen one-stop zones from -7 to +7 centred on the
whole stops, with a horizontal numbered legend. Colour palette designed for
this plugin. Color Analyzer keeps the previous reading unchanged.

Base grain made finer and quieter (28 October 2026): Amount 1 / Size 1 now
give 75 % of the measured grain strength at 85 % of its size. The measured
grain read too coarse and too present on real footage.
